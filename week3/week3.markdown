# Python数据分析第三周复盘报告

## 一、本周学习内容

### 1. 医学影像预处理（SimpleITK）
- [1] 合成测试影像生成：GaussianSource 创建高斯球体模拟病灶，AdditiveGaussianNoise 模拟噪声
- [2] 影像参数提取：尺寸、像素间距、原点、方向矩阵、像素类型
- [3] 强度统计分析：StatisticsImageFilter 获取均值、标准差、方差、最大/最小值
- [4] 三种归一化方法对比：
  - Min-Max 归一化 → 映射到 [0, 1]
  - Z-Score 标准化 → 均值为0、标准差为1
  - RescaleIntensity → 映射到 [0, 255]（8-bit 显示）
- [5] 多方位可视化：横断面（Axial）、冠状面（Coronal）、矢状面（Sagittal）
- [6] 强度直方图对比：原始 vs 三种归一化后的分布变化

### 2. 医保大数据清洗分析（Pandas + Matplotlib）
- [1] 模拟数据自动生成：基于业务规则构造 500 条医保记录（性别、年龄、医保类型、就诊类型、科室、费用）
- [2] 人为制造数据问题：
  - 缺失值：随机删除总费用（5%）、年龄（3%）、科室（8%）
  - 异常值：负费用、极高费用（IQR 异常）、异常高龄（>120）、报销比例>1
- [3] 数据清洗策略：
  - IQR 异常值检测与剔除
  - 分组中位数填充（总费用按就诊类型、报销比例按医保类型）
  - 全局中位数填充（年龄）
  - 众数填充（科室）
- [4] 分组统计：按就诊类型、医保类型、科室多维度汇总
- [5] 6 合 1 可视化报告：饼图、柱状图、直方图、箱线图、散点图 + 横向柱状图
- [6] 月度趋势分析：费用与报销趋势、就诊记录数月变化

### 3. 编码与兼容性问题解决

### 文献 1：基于噪声自适应感知的低场MRI图像增强方法

| 项目 | 内容 |
|------|------|
| **作者** | 刘琪, 胡宇韬, 杨淳沨, 陈阳 |
| **单位** | 南方医科大学 / 东南大学 |
| **期刊** | 中国医学物理学杂志, 2026, 43(3): 293-299 |
| **基金** | 国家杰出青年科学基金（T2225025） |

**研究问题**：低场 MRI 设备成本低、普及性强，但图像存在低信噪比（SNR）和高噪声问题，限制了临床应用。

**方法**：
1. **数据构建**：在高场 MRI 的 K 空间数据上加噪声并进行图像域欠采样，模拟生成低场图像，解决缺乏一一对应高场-低场配对训练数据的问题
2. **模型设计**：提出带有噪声自适应感知分支的双路去噪增强网络，利用 IXI 和 fastMRI 公开数据集训练
3. **质量评估**：引入弗雷歇初始距离（FID）和学习型感知图像块相似度（LPIPS）量化增强效果

**结果**：在真实低场数据上表现最优（IXI 训练 FID=0.4729, LPIPS=149.65；fastMRI 训练 FID=0.4734, LPIPS=148.43），有效保留细节的同时显著去噪。

**与本周作业的关联**：本文学到的影像增强思路（合成数据→预处理→模型训练→质量评估）与作业 1 的影像归一化预处理流程一脉相承，影像质量评估指标（FID、LPIPS）扩展了对归一化效果的量化理解。

### 文献 2：三角纤维软骨复合体的损伤诊断——基于MRI影像组学

| 项目 | 内容 |
|------|------|
| **作者** | 高悦, 程琳, 李逸凡, 马常栋, 侯增昊, 王山山 |
| **单位** | 滨州医学院附属医院放射科 / 医学影像学院 |
| **期刊** | 分子影像学杂志, 2025, 48(7): 821-826 |
| **基金** | 国家级/校级大学生创新训练项目 |

**研究问题**：三角纤维软骨复合体（TFCC）解剖精细复杂，损伤易漏诊、误诊，传统 MRI 依靠放射科医师主观经验。

**方法**：
1. 回顾性分析 96 例关节镜确诊患者（TFCC 损伤组 62 例 / 正常组 34 例）
2. 基于 MRI 多序列（T1WI、T2WI、PD-FS）勾画 ROI 并提取 1,000+ 影像组学特征
3. LASSO 降维筛选最佳特征子集
4. 对比 6 种机器学习算法（CSVC、NuSVC、RF、LR、AdaBoost、XGBoost）
5. 构建 Nomogram 列线图整合组学特征与临床指标

**关键结果**：
- NuSVC 在训练集 AUC 最高（0.8570），RF 在测试集表现稳定
- Nomogram 模型：训练集 AUC 0.9738，测试集 AUC 0.9250，显著优于临床模型（P<0.05）

**与本周作业的关联**：特征提取→筛选→建模的机器学习全流程，以及多序列数据融合的思路，与医保作业中多维度数据分组统计和异常检测的逻辑高度相似。

### 文献 3：医学影像技术参数对图像质量的核心影响——基于CT、MRI与DR的实证分析

| 项目 | 内容 |
|------|------|
| **作者** | 王琳 |
| **期刊** | 医学影像技术, 2025, 第 24 期 |

**研究问题**：CT、MRI、DR 参数设定如何影响空间分辨率、噪声、对比度和伪影，是否能通过参数优化在不降低诊断质量的前提下减少辐射剂量或提高效率。

**方法**：
1. 理论机制分析：梳理各模态物理参数对图像质量指标的量化影响路径
2. 实证数据验证：引用权威期刊临床研究数据，系统回顾参数优化的实际效果

**关键参数与发现**：
| 模态 | 关键参数 | 优化效果 |
|------|----------|----------|
| CT | kVp、mAs、层厚、重建算法 | 辐射剂量降低 50%～80% |
| MRI | 场强、TR/TE、矩阵、并行采集 | 成像效率加速 2～4 倍 |
| DR | kVp、mAs、探测器 DQE | 辐射剂量降低 50%～80% |

**结论**：依据患者个体情况（体型、部位、临床需求）个性化设置参数，可在保证诊断质量的前提下实现低剂量或高效成像。

**与本周作业的关联**：本文"参数→质量"的因果分析框架与作业 1 中"不同归一化方法对影像强度分布的影响"形成对照，参数优化思想贯穿医学影像全流程。

### 文献 4：CT/MRI/超声多模态影像融合AI技术在战创伤诊断中的研究进展

| 项目 | 内容 |
|------|------|
| **作者** | 周文华, 吴斌, 李伟, 张安宇, 陈天金, 孟亮亮, 席晓萍 |
| **期刊** | 武警医学, 2026, 37(6): 533-536 |
| **DOI** | 10.3969/j.issn.1004-3594.2026.06.013 |

**研究问题**：现代战争模式下战创伤呈现突发性强、复合伤多、伤情隐匿、救治紧迫的特点，单一模态影像难以满足全面诊断需求。

**核心论点**：
1. **各模态局限**：CT 对骨结构敏感但软组织分辨率低，MRI 软组织优异但检查耗时，超声便携但对深部结构受限

3. **未来方向**：构建"结构-功能-动态"三位一体的战场医学影像诊断体系

**展望**：多模态融合 AI 技术有望实现战创伤的快速分诊、智能化危急值报告、远程专家会诊辅助。

**与本周作业的关联**：本文多模态数据融合的思想与作业 1 中多方位影像归一化、作业 2 中多维度数据清洗统计的思路相呼应——都是将异构数据整合为统一、可分析的标准化形式。

## 四、遇到的报错及解决方案

### 报错 1：SimpleITK 未安装

- **场景**：`ModuleNotFoundError: No module named 'SimpleITK'`
- **解决**：`pip install SimpleITK`

### 报错 2：GaussianSource 参数格式错误

- **场景**：`TypeError: GaussianSource() takes at most 5 arguments`
- **原因**：sigma（各方向标准差）和 mean（球体中心位置）需以 list 形式传入
- **解决**：

```python
# 错误写法
sitk.GaussianSource(sitk.sitkFloat32, image_size, sphere_radius,
                    sphere_center[0], sphere_center[1], sphere_center[2], sphere_intensity)

# 正确写法
sitk.GaussianSource(sitk.sitkFloat32, image_size,
                    [float(sphere_radius)] * 3,
                    [float(sphere_center[0]), float(sphere_center[1]), float(sphere_center[2])],
                    float(sphere_intensity))
```

### 报错 3：Windows GBK 编码不支持 emoji 字符

- **场景**：`UnicodeEncodeError: 'gbk' codec can't encode character '\u2705'`
- **解决**：在脚本 import 语句前添加 UTF-8 强制编码

```python
import sys
import io
sys.stdout = io.TextIOWrapper(sys.stdout.buffer, encoding='utf-8')
```

### 报错 4：pyright 大量类型检查警告

- **场景**：400+ 条 `reportMissingTypeStubs`、`reportUnknownMemberType` 警告
- **原因**：pandas、matplotlib、SimpleITK 未安装类型存根（`.pyi` 文件），pyright 无法推断类型
- **性质**：仅影响 IDE 显示，不影响程序运行
- **解决**：可忽略，不影响运行；或安装 `pandas-stubs` 等类型存根包
