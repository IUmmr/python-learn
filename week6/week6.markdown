### 习题1：Python 基础综合题（周一）

**文件**：`exercise1_python_basics.py`

| 步骤 | 实现方式 |
|------|----------|
| 过滤负数 | 列表推导式 `[x for x in numbers if x >= 0]` |
| 最大/最小/平均 | `max()` / `min()` / `sum()/len()` |
| 冒泡排序 | 双重循环逐趟比较相邻元素，加入 `swapped` 标志提前终止 |

**运行结果**：
```
原始列表: [3.5, -2, 7, 0, -9.5, 12, 4, -1, 8.2, 5, -3.3, 2]
过滤后:   [3.5, 7, 0, 12, 4, 8.2, 5, 2]
最大值: 12 | 最小值: 0 | 平均值: 5.2125
升序排列: [0, 2, 3.5, 4, 5, 7, 8.2, 12]（与 sorted() 一致）
```

**复习要点**：函数封装、列表推导式、冒泡排序算法思想、边界情况处理（全负数列表返回 None）。

### 习题2：数据分析综合题（周二）

**文件**：`exercise2_data_analysis.py`

| 步骤 | 实现方式 |
|------|----------|
| 生成数据集 | 60 行「姓名、年龄、收入」，人为制造 5 个收入缺失值 |
| 缺失值填充 | `df['收入'].fillna(收入均值)` |
| 剔除异常 | 条件筛选 `df['收入'] <= 200000` |
| 年龄段分组 | `pd.cut(年龄, bins=[17,35,59,200], labels=[青年,中年,老年])` |
| 分组统计 | `groupby('年龄段')['收入'].mean()` |
| 可视化 | 各组平均收入柱状图 + 数值标注 |

**运行结果**：剔除 17 条高收入异常后剩余 43 条，老年组平均收入 105,252 元、青年组 100,477 元、中年组 111,921 元。

**产出**：`exercise2_avg_income.png`、`exercise2_cleaned.csv`

**复习要点**：`pd.cut` 分箱、`groupby` 聚合、柱状图标注技巧。

### 习题3：医学影像巩固题（周三）

**文件**：`exercise3_medical_image.py`

| 步骤 | 实现方式 |
|------|----------|
| 生成二维影像 | SimpleITK `GaussianSource` 二维高斯斑 + `AdditiveGaussianNoise` + `Clamp` |
| 获取 numpy 数组 | `sitk.GetArrayFromImage(image)` |
| 归一化到 [0,1] | Min-Max: `(arr - min) / (max - min)` |
| 二值分割 | `(arr_norm > 0.5).astype(np.uint8)` |
| 统计输出 | 打印数组形状、二值像素总和、前景占比 |

**运行结果**：128×128 影像，归一化后范围 [0,1]，二值分割前景像素 3917 个，占比 23.91%。

**产出**：`exercise3_binary_seg.png`（原始/归一化/二值三图对比）

**复习要点**：SimpleITK 与 numpy 互操作、Min-Max 归一化公式、布尔索引二值化。

### 习题4：医保大数据综合复习题（周四）

**文件**：`exercise4_medical_insurance.py`

| 步骤 | 实现方式 |
|------|----------|
| 生成数据 | 250 条：年龄、就诊费用、就诊次数、报销比例、报销费用，12 条费用缺失 |
| 填充缺失值 | 费用均值填充 + 同步补齐报销费用 |
| 剔除异常 | `df['就诊费用'] <= 80000` |
| 筛选老年 | `df[df['年龄'] >= 65]` |
| 统计 | 老年平均就诊费用 / 平均就诊次数 / 平均报销费用 |
| 可视化 | 老年患者报销费用直方图 + 平均线标注 |

**运行结果**：剔除 3 条 >80000 异常记录后剩 247 条；65 岁以上老年患者 100 人，平均就诊费用 29,238 元、平均就诊次数 5.72 次、平均报销费用 20,733 元。

**产出**：`exercise4_elderly_hist.png`、`exercise4_cleaned.csv`

**复习要点**：模拟数据制造缺失与异常、字段联动补齐（费用→报销）、直方图平均线标注。

> 调试心得：第一版数据生成逻辑（`clip(100,100000)`）恰好没有超过 80000 的记录，导致"剔除异常"步骤无实际效果。通过人为放大 20 条样本的费用（×2.0~2.8）确保异常记录存在，让每个步骤都真正执行到。

## 四、薄弱知识点清单

### 4.1 复习中发现的问题

| 编号 | 薄弱知识点 | 具体表现 | 严重程度 |
|------|-----------|----------|----------|
| 1 | **冒泡排序算法** | 需重新推导双重循环边界条件（`n-1-i`），对提前终止优化不熟悉 | 中 |
| 2 | **pd.cut 分箱边界** | 首次忘记边界参数 `right=True` 会改变区间归属；分箱标签与边界需反复核对 | 中 |
| 3 | **数据生成中的异常设计** | 习题4第一版模拟数据因范围限制导致无异常可剔除，暴露了"构造数据时未验证业务约束"的问题 | 中 |
| 4 | **SimpleITK 参数格式** | `GaussianSource` 的 sigma/mean 需以 list 传入，二维与三维影像的参数结构易混淆 | 低 |
| 5 | **numpy 数组运算细节** | 二值化 `(arr > 0.5).astype(np.uint8)` 与 `astype(int)` 的语义区别需明确 | 低 |
| 6 | **CNN 各层作用** | 能写代码但难以清晰解释 BatchNorm 为什么加速收敛、Dropout 如何防过拟合 | 中 |
| 7 | **验证集划分** | 首次使用 `random_split`，对随机种子、子集长度参数不熟悉 | 低 |
| 8 | **训练日志设计** | 之前只会 epoch 级打印，本次新增 step 级打印后对"训练进度可见性"有了新认识 | 低 |

### 4.2 薄弱原因分析

1. **算法手写能力不足**：平时依赖内置函数（`sorted`、`max`），基本算法（冒泡排序）缺乏手写训练
2. **API 参数记忆不牢**：`pd.cut`、`random_split` 等函数的边界与参数含义使用不频繁
3. **数据构造缺乏验证闭环**：生成模拟数据时没有先检查数据是否符合预期的业务分布
4. **理论理解浮于表面**：CNN 层的作用停留在"知道怎么用"，未达到"能讲清为什么"
