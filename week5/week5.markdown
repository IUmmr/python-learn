## 五、问题与改进方向

### 5.1 现存问题

1. **类型检查器误报较多**：pyright 对 pandas/matplotlib/SimpleITK 产生大量 `MissingTypeStubs` 警告
2. **Windows 编码问题偶有发生**：部分脚本在默认 GBK 编码下运行 emoji 报错
3. **数据清洗方法单一**：主要依赖均值/中位数填充，缺少插值、回归填充、孤立森林等方法
4. **模型评估维度不足**：第4周仅关注准确率，对 Precision/Recall/F1 掌握不深
5. **PyTorch 工程化不足**：尚未实践自定义 Dataset、迁移学习、训练日志记录
6. **Git 使用偏基础**：只会 `add/commit`，不熟悉分支、标签、规范的提交信息

### 5.2 改进措施

| 问题 | 改进措施 |
|------|----------|
| pyright 误报 | 安装 `pandas-stubs`，配置 `pyrightconfig.json` |
| 编码报错 | 所有文件读写统一 `encoding='utf-8'` |
| 清洗方法单一 | 学习 `interpolate`、`IsolationForest`、`KNNImputer` |
| 评估维度不足 | 所有分类任务补充混淆矩阵与分类报告 |
| PyTorch 工程化 | 练习自定义 Dataset、ResNet 迁移学习 |
| Git 使用基础 | 学习分支操作与提交规范 |

## 六、核心收获总结

1. **建立了完整的数据分析链路**：从 Python 基础 → 数据分析 → 领域应用（医学影像/医保）→ 深度学习，形成递进式知识框架。
2. **养成了工程化意识**：虚拟环境、编码兼容、Git 版本管理、代码归档成为日常习惯。
3. **提升了问题定位能力**：面对报错不再慌张，能够根据错误信息定位原因并修复，同时记录解决方案。
4. **理解了"数据预处理优先"**：无论是影像归一化还是表格清洗，数据质量决定模型上限。
5. **掌握了可视化表达**：学会了用图表呈现数据分布、训练过程和分类结果，为汇报和论文打下基础。
6. **认识到复盘的价值**：每周复盘不仅是记录，更是将零散知识系统化的关键步骤。
